# ESPM 154 Spatial Scale Exercise

This repository contains the student files for the ESPM 154 spatial-scale exercise.

## Files

- `ESPM154_Spatial_Scale_Exercise.Rmd` — exercise handout and R code
- `ESPM154_genetic_diversity_landscape.csv` — fixed simulated landscape used by the exercise

## Running on Berkeley DataHub

The exercise is designed to be run in RStudio on Berkeley DataHub. Keep the R Markdown file and CSV in the same directory.

Open `ESPM154_Spatial_Scale_Exercise.Rmd` in RStudio and run the chunks in order.

The exercise uses only base R functions, so no additional R packages should be required.

## Instructor distribution

The recommended distribution method is `nbgitpuller`. Students click a single link; the repository is copied into their DataHub home directory and RStudio opens automatically.

See Berkeley DataHub documentation for current nbgitpuller guidance.
